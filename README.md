# Cybersecurity Awareness Assessment

A practical employee-focused cybersecurity awareness assessment prepared for the **Invexom Cybersecurity Internship** task.

**Repository:** https://github.com/hemanthkumar1012/invexom-cybersecurity-awareness-assessment

## Project objective

Create a practical awareness assessment for a fictional small organization and identify common security risks employees could encounter. Each risk includes:

- Risk description
- Potential impact
- Example scenario
- Recommended prevention

The project also includes a concise employee cybersecurity checklist and submission/video guidance.

## Fictional organization

**NovaBridge Solutions** is a fictional small professional-services organization with approximately 25 employees using email, cloud storage, laptops, mobile devices, and common SaaS applications.

## Risks covered

1. Weak or reused passwords
2. Phishing and credential theft
3. Unsafe downloads and malicious attachments
4. Unsecured devices
5. Social engineering
6. Improper data sharing
7. Outdated software and operating systems
8. Untrusted links and websites
9. Unsafe public Wi-Fi
10. Unauthorized USB/removable media
11. Missing multi-factor authentication (MFA)
12. Excessive access privileges

## Basic response rule

**Stop → Verify → Report**

When something suspicious happens:
1. Stop before clicking, paying, sharing data, or approving access.
2. Verify the request using an independent trusted channel.
3. Report suspected phishing, malware, lost devices, or accidental data disclosure promptly.

## Scope

This is an employee security-awareness exercise for a fictional organization. It is not a penetration test, technical vulnerability assessment, compliance audit, or formal enterprise risk register.
