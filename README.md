# Cybersecurity Awareness Assessment

A basic employee-focused cybersecurity awareness assessment prepared for the **Invexom Cybersecurity Internship** task.

## Project objective

Create a practical awareness assessment for a fictional small organization and identify at least 10 common security risks. Each risk includes:

- Risk description
- Potential impact
- Example scenario
- Recommended prevention

The project also includes a short employee cybersecurity checklist.

## Deliverables

- `cybersecurity_awareness_assessment.md` - complete written assessment
- `employee_security_checklist.md` - printable checklist
- `submission_description.txt` - text for the internship submission form
- `video_script.txt` - short script for the required demonstration video
- `Cybersecurity_Awareness_Assessment.pdf` - polished PDF version

## Organization used in the assessment

**NovaBridge Solutions** is fictional and represents a small professional-services organization with approximately 25 employees.

## Key topics

Password security, phishing, malicious downloads, device security, social engineering, data sharing, software updates, unsafe links, public Wi-Fi, removable media, MFA, and least privilege.

## Educational note

This project is an awareness document, not a penetration test or technical security audit.
